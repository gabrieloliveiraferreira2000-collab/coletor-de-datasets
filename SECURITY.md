# Segurança

Se encontrar uma vulnerabilidade que possa expor dados locais ou permitir comportamento inesperado, evite publicar detalhes exploráveis numa issue pública. Use os avisos de segurança privados do GitHub quando estiverem habilitados no repositório; se não estiverem, peça contato privado por um canal da pessoa mantenedora.

Este aplicativo acessa os endereços configurados pela pessoa usuária e grava arquivos localmente. Use somente fontes confiáveis e revise o perfil antes de iniciar uma coleta.
